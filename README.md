# Overview

This is my first time coding with Javascript so I coded a simple To-Do list that runs in your browser using HTML

This simple To-Do list lets the user add, remove, and mark tasks for completion. When there are multiple tasks, the user can rearrange the order of the tasks in the array and how they are displayed while running in the browser. Marking and unmarking a task are as simple as clicking on the task, which clearly marks off the task as completed.

This is the first Javascript code I have written so I wanted to get a good understanding of setting up the body and style of the HTML that will run in the browser.
